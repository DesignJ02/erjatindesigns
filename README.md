# Jatin Srivastava — Portfolio

Personal UX portfolio inspired by a Framer reference layout, featuring LocEarn and Kangaru case studies from the pitch deck.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

Edit contact details, LinkedIn, and resume links in `src/lib/content.ts`.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
