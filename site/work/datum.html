A token-first design system

A dark-first design system I built from scratch: colour, type, spacing and radii as tokens, nine components, and Storybook documentation. This portfolio is built on it.

StatusLive
RoleDesigner, owner
ScopeTokens, components, docs
TypePersonal project
01Preview

Tokens first, components second

Datum starts from tokens, not components. Every colour, size, radius and shadow in the system is a named variable, and the components are thin layers on top of them. This site uses Datum's tokens and its Button, Tag and Tooltip as they are documented.

01

Foundations

Nine colour palettes with ten shades each, a 4px spacing base, twelve radii, five shadows, and a stroke scale.

02

Type

General Sans for interface text and DM Mono for code and tokens, in a display-to-label scale.

03

Components

Button, Input, Avatar, Checkbox, Radio, Toggle, Tag and Badge, Tooltip and Empty State, each with states and usage notes.

04

Documentation

A Next.js site with a live playground per component, plus Storybook stories for foundations and components.

See it liveThe full system, with playgrounds and code, is at datum-by-jatin.vercel.app.
